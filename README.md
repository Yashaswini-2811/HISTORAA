# HISTORAA

Free static hackathon website prototype.

Features: 7-civilization map, 100-page-format comics, 50-page Women Who Changed History book, quiz with hints, daily modern Brain Blast, collectible cards, XP, and an original treasure-run prototype.

## GitHub Pages
Create a public repository, upload all files, then **Settings → Pages → Deploy from branch → main → / (root) → Save**.

Expand the JSON/data structure and content after the demo. Verify historical facts and use only images/assets you have permission to publish.


## Quiz bank
HISTORAA now includes exactly 1,000 history questions across India, Egypt, Greece, China, Rome, Maya and Japan. Questions are randomized on each session. Wrong answers reveal a hint and a historical fact instead of only showing failure.
